# Auditoría MPD — Landing page

Public landing page for the **Auditoría MPD** service (Modelo de Prevención de Delitos, Ley 20.393 / Ley 21.595, Chile).

Live: https://atspuler.github.io/auditoria-mpd/

This repo contains a single static HTML file served via GitHub Pages. Content is authored elsewhere; updates are published by replacing `index.html` and pushing to `main`.
